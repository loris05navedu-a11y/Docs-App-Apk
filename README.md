# Docs-App-Apk

DocsApp Suite, une suite bureautique pour Android : documents, tableurs,
présentations, PDF, scanner, dictée, fiches de révision… et l'édition
partagée, pour écrire à plusieurs en direct.

L'édition partagée s'appuie sur un projet Firebase : sa mise en place et
son serveur (règles, e-mail d'invitation, liens) sont décrits dans
[firebase/README.md](firebase/README.md).
